# ModalWindow

Application-level window presets for the core modal controller.

```text
ModalWindow/
├─ Modal/
├─ Dialog/
├─ Fullscreen/
├─ SidebarLeft/
└─ SidebarRight/
```

Each preset starts as configuration only. Presenter/Position/Wrapper/etc. are added inside the preset only when its behavior differs from the core defaults.
